# 附录 D LLVM IR 指令速查表

## D.0 用法

这是一份**查阅用**的表，不是教程。你不需要背任何一条。

- 想知道「C 的某个运算对应哪条指令」→ 看 [D.1](#d1-按功能查c-运算-ir-指令)
- 想知道「某条指令的完整语法」→ 看 [D.2](#d2-指令语法全表)
- 想知道「某个标志位能加在哪些指令上」→ 看 [D.3](#d3-标志位与属性速查)
- 想知道「某个比较谓词是什么意思」→ 看 [D.4](#d4-比较谓词全表)

所有条目在 **LLVM 18.1.3** 上验证过。类型一律用 `i32`/`ptr`/`double` 举例，实际可替换为任意合法类型。

## D.1 按功能查：C 运算 → IR 指令

### 整数算术

| C | IR | 说明 |
|---|---|---|
| `a + b` | `add i32 %a, %b` | 有符号时 clang 加 `nsw` |
| `a - b` | `sub i32 %a, %b` | 同上 |
| `a * b` | `mul i32 %a, %b` | 同上 |
| `-a` | `sub nsw i32 0, %a` | IR 没有取负指令 |
| `a / b`（`int`） | `sdiv i32 %a, %b` | 除零是 UB |
| `a / b`（`unsigned`） | `udiv i32 %a, %b` | |
| `a % b`（`int`） | `srem i32 %a, %b` | |
| `a % b`（`unsigned`） | `urem i32 %a, %b` | |

### 位运算与移位

| C | IR | 说明 |
|---|---|---|
| `a & b` | `and i32 %a, %b` | |
| `a \| b` | `or i32 %a, %b` | |
| `a ^ b` | `xor i32 %a, %b` | |
| `~a` | `xor i32 %a, -1` | IR 没有 `not` 指令 |
| `a << b` | `shl i32 %a, %b` | |
| `a >> b`（有符号） | `ashr i32 %a, %b` | 补符号位 |
| `a >> b`（无符号） | `lshr i32 %a, %b` | 补 0 |

### 比较（结果都是 `i1`）

| C | IR |
|---|---|
| `a < b`（`int`） | `icmp slt i32 %a, %b` |
| `a <= b`（`int`） | `icmp sle i32 %a, %b` |
| `a > b`（`int`） | `icmp sgt i32 %a, %b` |
| `a >= b`（`int`） | `icmp sge i32 %a, %b` |
| `a < b`（`unsigned`） | `icmp ult i32 %a, %b` |
| `a == b` | `icmp eq i32 %a, %b` |
| `a != b` | `icmp ne i32 %a, %b` |
| `p == NULL` | `icmp eq ptr %p, null` |

### 浮点

| C | IR |
|---|---|
| `a + b`（`double`） | `fadd double %a, %b` |
| `a - b` | `fsub double %a, %b` |
| `a * b` | `fmul double %a, %b` |
| `a / b` | `fdiv double %a, %b` |
| `fmod(a,b)` | `frem double %a, %b` |
| `-a` | `fneg double %a` |
| `a < b` | `fcmp olt double %a, %b` |
| `a != b` | `fcmp une double %a, %b` |
| `a` 是 NaN | `fcmp uno double %a, %a` |

### 类型转换

| C | IR | 方向 |
|---|---|---|
| `(long)x`，`x` 是 `int` | `sext i32 %x to i64` | 整数变宽，保符号 |
| `(unsigned long)x` | `zext i32 %x to i64` | 整数变宽，补 0 |
| `(int)y`，`y` 是 `long` | `trunc i64 %y to i32` | 整数变窄 |
| `(char)x` | `trunc i32 %x to i8` | |
| `(_Bool)x` | `icmp ne i32 %x, 0` | 真值化 |
| `(double)x`，`x` 是 `int` | `sitofp i32 %x to double` | 有符号整数→浮点 |
| `(double)u`，`u` 是 `unsigned` | `uitofp i32 %u to double` | 无符号整数→浮点 |
| `(int)d`，`d` 是 `double` | `fptosi double %d to i32` | 浮点→有符号整数 |
| `(unsigned)d` | `fptoui double %d to i32` | 浮点→无符号整数 |
| `(double)f`，`f` 是 `float` | `fpext float %f to double` | 浮点变宽 |
| `(float)d` | `fptrunc double %d to float` | 浮点变窄 |
| `(uintptr_t)p` | `ptrtoint ptr %p to i64` | 指针→整数 |
| `(void*)x` | `inttoptr i64 %x to ptr` | 整数→指针 |
| `(int)x`，`x` 是 `unsigned` | **无指令** | 都是 `i32`，恒等 |

### 内存与地址

| C | IR |
|---|---|
| `*p` | `load i32, ptr %p, align 4` |
| `*p = v` | `store i32 %v, ptr %p, align 4` |
| `p->field` | `getelementptr inbounds %struct.S, ptr %p, i32 0, i32 <字段号>` |
| `a[i]` | `getelementptr inbounds i32, ptr %a, i64 %i` |
| `&g`（全局） | 直接用 `@g`（它本身就是指针） |
| `&x`（局部） | `alloca` 得到的那个 `ptr` |
| 局部变量 | `alloca i32, align 4` |
| VLA | `alloca i32, i32 %n, align 4` |

### 控制流

| C | IR |
|---|---|
| `return v;` | `ret i32 %v` |
| `return;` | `ret void` |
| 无条件跳转 | `br label %target` |
| `if (c)` | `br i1 %cond, label %then, label %else` |
| `switch` | `switch i32 %x, label %default [ i32 0, label %c0 ... ]` |
| `c ? a : b`（无副作用） | `select i1 %c, i32 %a, i32 %b` |
| `c ? a : b`（有分支） | `br` + `phi` |
| 汇合点取值 | `phi i32 [ %v1, %b1 ], [ %v2, %b2 ]` |
| 不可达 | `unreachable` |
| 函数调用 | `call i32 @f(i32 %a)` |
| 间接调用 | `call i32 %fp(i32 %a)` |

## D.2 指令语法全表

下面按类别列出**完整语法**。`<ty>` 表示类型，`<val>` 表示值。

### 终结指令（每个基本块必须有且只有一个）

```llvm
ret void
ret <ty> <val>
br label %<label>
br i1 <cond>, label %<iftrue>, label %<iffalse>
switch <ty> <val>, label %<default> [ <ty> <c1>, label %<l1> ... ]
indirectbr ptr <addr>, [ label %<l1>, label %<l2> ... ]
unreachable
invoke <ty> @<fn>(<args>) to label %<normal> unwind label %<exception>
resume <ty> <val>
```

### 二元运算

```llvm
<op> <ty> <op1>, <op2>        ; 通用形式

; 整数
add   sub   mul   udiv   sdiv   urem   srem
shl   lshr  ashr  and    or     xor

; 浮点
fadd  fsub  fmul  fdiv   frem
```

### 一元运算

```llvm
fneg <ty> <val>
```

### 比较

```llvm
icmp <pred> <ty> <op1>, <op2>
fcmp <pred> <ty> <op1>, <op2>
```

### 类型转换

```llvm
trunc  <ty1> <val> to <ty2>     ; 整数变窄
zext   <ty1> <val> to <ty2>     ; 整数变宽（补 0）；可加 nneg
sext   <ty1> <val> to <ty2>     ; 整数变宽（补符号）
fptrunc <ty1> <val> to <ty2>    ; 浮点变窄
fpext   <ty1> <val> to <ty2>    ; 浮点变宽
fptoui  <ty1> <val> to <ty2>    ; 浮点 → 无符号整数
fptosi  <ty1> <val> to <ty2>    ; 浮点 → 有符号整数
uitofp  <ty1> <val> to <ty2>    ; 无符号整数 → 浮点
sitofp  <ty1> <val> to <ty2>    ; 有符号整数 → 浮点
ptrtoint ptr <val> to <ty>      ; 指针 → 整数
inttoptr <ty> <val> to ptr      ; 整数 → 指针
bitcast <ty1> <val> to <ty2>    ; 同位宽重解释
addrspacecast ptr <val> to ptr addrspace(<n>)
```

### 内存

```llvm
alloca <ty>, align <n>
alloca <ty>, <ty> <count>, align <n>          ; 动态大小

load <ty>, ptr <ptr>, align <n>
load volatile <ty>, ptr <ptr>, align <n>
load atomic <ty>, ptr <ptr> <ordering>, align <n>

store <ty> <val>, ptr <ptr>, align <n>
store volatile <ty> <val>, ptr <ptr>, align <n>
store atomic <ty> <val>, ptr <ptr> <ordering>, align <n>

getelementptr [inbounds] <ty>, ptr <ptr>, <ty> <idx> [, <ty> <idx> ...]

fence <ordering>
cmpxchg [weak|strong] ptr <ptr>, <ty> <cmp>, <ty> <new> <success_ordering> <failure_ordering>
atomicrmw <op> ptr <ptr>, <ty> <val> <ordering>
```

### 其他

```llvm
phi <ty> [ <val1>, %<label1> ], [ <val2>, %<label2> ], ...
select i1 <cond>, <ty> <val1>, <ty> <val2>
call [fast-math flags] <ty> @<fn>(<args>)
call <ty> <fnptr>(<args>)                      ; 间接调用
tail call <ty> @<fn>(<args>)
va_arg <ty>, ptr <ap>
landingpad <ty> cleanup | catch <ty> <val>
freeze <ty> <val>
extractvalue <agg> <val>, <idx> [, <idx> ...]
insertvalue <agg> <val>, <ty> <elt>, <idx> [, <idx> ...]
extractelement <vec> <val>, <ty> <idx>
insertelement <vec> <val>, <ty> <elt>, <ty> <idx>
shufflevector <vec> <v1>, <vec> <v2>, <vec> <mask>
```

## D.3 标志位与属性速查

### 哪些指令支持哪些标志位

| 标志 | 含义 | 可用于 |
|---|---|---|
| `nsw` | 有符号溢出 → poison | `add` `sub` `mul` `shl` |
| `nuw` | 无符号溢出 → poison | `add` `sub` `mul` `shl` |
| `exact` | 除/移位无余数，否则 poison | `udiv` `sdiv` `lshr` `ashr` |
| `nneg` | 源值非负 | `zext` |
| `inbounds` | 地址算在对象内 | `getelementptr` |
| `disjoint` | 各操作数的置位互不重叠 | **仅 `or`**（`and`/`xor` 会报 `expected type`） |

**注意 `trunc` 不支持任何标志位**（详见 [附录 A.1.3](21-附录A-与常见说法的差异.md#a13-trunc-不接受任何标志位)）。

### 浮点快速数学标志

| 标志 | 含义 |
|---|---|
| `nnan` | 假设无 NaN |
| `ninf` | 假设无无穷 |
| `nsz` | 忽略 ±0 的区别 |
| `arcp` | 允许除法换成乘倒数 |
| `contract` | 允许合并为 FMA |
| `afn` | 允许近似函数 |
| `reassoc` | 允许重结合（**破坏结合律**） |
| `fast` | 以上全部（最激进） |

可用于 `fadd` `fsub` `fmul` `fdiv` `frem` `fneg` `fcmp` `call`（针对返回浮点的调用）。

### 常见函数属性

| 属性 | 含义 |
|---|---|
| `noinline` / `alwaysinline` / `inlinehint` | 内联控制 |
| `optnone` | **禁止一切优化**（`-O0` 用；会静默让所有 pass 失效） |
| `optsize` / `minsize` | 优化体积 |
| `noreturn` | 永不返回 |
| `nounwind` | 不抛异常 |
| `willreturn` | 一定会返回 |
| `mustprogress` | 循环必须在有限步内结束 |
| `readnone` / `readonly` / `writeonly` | 内存访问行为（旧式） |
| `memory(none)` / `memory(read)` / `memory(write)` | 内存访问行为（新式，推荐） |
| `norecurse` | 不直接递归 |
| `nofree` / `nosync` | 不释放内存 / 无同步操作 |
| `cold` / `hot` | 执行频率提示 |
| `uwtable` | 生成栈展开表 |
| `ssp` / `sspstrong` | 栈保护 |

### 常见参数与返回值属性

| 属性 | 位置 | 含义 |
|---|---|---|
| `noundef` | 参数/返回值 | 不会是 `undef`/`poison` |
| `zeroext` / `signext` | 参数/返回值 | 零扩展 / 符号扩展到寄存器宽度 |
| `noalias` | 参数/返回值 | 不与其他指针别名（C 的 `restrict`） |
| `nocapture` | 参数 | 不会被存到别处 |
| `readonly` / `writeonly` / `readnone` | 参数 | 不通过它写 / 读 / 读写 |
| `dereferenceable(N)` | 参数 | 至少指向 N 字节有效内存 |
| `dereferenceable_or_null(N)` | 参数 | 要么 null，要么可解引用 N 字节 |
| `align N` | 参数 | 指针对齐到 N |
| `returned` | 参数 | 返回值就是这个参数 |
| `byval` / `byref` | 参数 | 按值 / 按引用传递聚合类型 |
| `sret` | 参数 | 结构体返回值的存放地址 |

### 链接属性

| 属性 | 对应 C | 说明 |
|---|---|---|
| （无） | 普通全局符号 | 外部可见 |
| `private` | — | 仅本模块，不进符号表 |
| `internal` | `static` | 仅本模块，进符号表（便于调试） |
| `available_externally` | — | 仅供内联，不生成代码 |
| `linkonce` / `linkonce_odr` | 模板/内联函数 | 可重复定义，保留一份 |
| `weak` / `weak_odr` | `__attribute__((weak))` | 可被更强定义覆盖 |
| `common` | 暂时定义 | 可与其他 `common` 合并 |
| `appending` | — | 仅用于 `llvm.global_ctors` 等 |
| `extern_weak` | `extern` + weak | 弱外部引用 |

### 可见性（写在 `global`/`constant` **之前**）

```llvm
@a = default global i32 1      ; 可省略不写
@b = hidden global i32 2
@c = protected global i32 3
```

### 调用约定

| 关键字 | 用途 |
|---|---|
| （省略，即 `ccc`） | C 调用约定，平台默认 |
| `fastcc` | LLVM 内部约定，**不能跨模块调用** |
| `coldcc` | 很少执行的路径 |
| `cc <n>` | 平台特定约定（如 `cc 10` 是 GHC） |

## D.4 比较谓词全表

### `icmp` 谓词（10 个）

| 谓词 | 含义 | 有无符号 |
|---|---|---|
| `eq` | 相等 | 无 |
| `ne` | 不等 | 无 |
| `ugt` | 大于 | 无符号 |
| `uge` | 大于等于 | 无符号 |
| `ult` | 小于 | 无符号 |
| `ule` | 小于等于 | 无符号 |
| `sgt` | 大于 | 有符号 |
| `sge` | 大于等于 | 有符号 |
| `slt` | 小于 | 有符号 |
| `sle` | 小于等于 | 有符号 |

**`eq`/`ne` 没有 `s`/`u` 变体** —— 相等就是逐位相等。

### `fcmp` 谓词（16 个）

`o` = **o**rdered：仅当两个操作数**都不是 NaN** 时才有意义。
`u` = **u**nordered：任一操作数为 NaN 时为**真**。

| 谓词 | 含义 |
|---|---|
| `false` | 恒假 |
| `oeq` | 有序且相等 |
| `ogt` | 有序且大于 |
| `oge` | 有序且大于等于 |
| `olt` | 有序且小于 |
| `ole` | 有序且小于等于 |
| `one` | 有序且不等 |
| `ord` | 有序（都不是 NaN） |
| `ueq` | 无序或相等 |
| `ugt` | 无序或大于 |
| `uge` | 无序或大于等于 |
| `ult` | 无序或小于 |
| `ule` | 无序或小于等于 |
| `une` | 无序或不等 |
| `uno` | 无序（至少一个是 NaN） |
| `true` | 恒真 |

### C 的浮点比较对应哪条

| C | 谓词 | 为什么 |
|---|---|---|
| `a < b` | `olt` | NaN 参与时 C 要求返回假 = 「有序且小于」 |
| `a <= b` | `ole` | 同上 |
| `a > b` | `ogt` | 同上 |
| `a >= b` | `oge` | 同上 |
| `a == b` | `oeq` | NaN 参与时返回假 |
| **`a != b`** | **`une`** | NaN 参与时返回**真**（NaN != NaN 为真） |

**最后一行是个经典陷阱**：`!=` 对应的是 `une`（无序**或**不等），不是 `one`。

### 位序

| 谓词 | 含义 |
|---|---|
| `slt` | 有符号小于 |
| `ult` | 无符号小于 |
| `eq` | 相等 |

`-1` 作为无符号数是 4294967295，所以 `(unsigned)-1 < 1` 为假，而 `-1 < 1` 为真 —— 同一个 `i32`，不同的谓词。**符号性不在类型里，在谓词里。**

## D.5 内建函数速查

内建函数名以 `llvm.` 开头，由后端直接生成代码。

| 类别 | 例子 |
|---|---|
| 内存 | `llvm.memcpy.p0.p0.i64`、`llvm.memmove`、`llvm.memset` |
| 位操作 | `llvm.ctpop`、`llvm.ctlz`、`llvm.cttz`、`llvm.bitreverse`、`llvm.bswap` |
| 整数数学 | `llvm.abs`、`llvm.smax`、`llvm.smin`、`llvm.umax`、`llvm.umin` |
| 浮点数学 | `llvm.fabs`、`llvm.sqrt`、`llvm.floor`、`llvm.ceil`、`llvm.round`、`llvm.fma` |
| 饱和运算 | `llvm.sadd.sat`、`llvm.uadd.sat`、`llvm.ssub.sat`、`llvm.usub.sat` |
| 溢出检查 | `llvm.sadd.with.overflow`、`llvm.umul.with.overflow` 等 |
| 调试/陷阱 | `llvm.trap`、`llvm.debugtrap`、`llvm.dbg.value` |
| 变参 | `llvm.va_start`、`llvm.va_end`、`llvm.va_copy` |
| 栈/帧 | `llvm.frameaddress`、`llvm.returnaddress`、`llvm.stacksave`、`llvm.stackrestore` |
| 向量 | `llvm.vector.reduce.add`、`llvm.masked.load`、`llvm.masked.store` |

**类型编码在名字里**：`llvm.ctpop.i32` 操作 `i32`；`llvm.memcpy.p0.p0.i64` 表示「目标地址空间 0 的指针、源地址空间 0 的指针、`i64` 长度」。这是因为 LLVM 的函数名不支持重载，所以用命名约定区分。

溢出检查类内建函数返回**结构体**，这是 IR 比 C 更强的地方：

```llvm
declare { i32, i1 } @llvm.sadd.with.overflow.i32(i32, i32)

%r    = call { i32, i1 } @llvm.sadd.with.overflow.i32(i32 %a, i32 %b)
%sum  = extractvalue { i32, i1 } %r, 0
%ovf  = extractvalue { i32, i1 } %r, 1
```

C 的 `__builtin_add_overflow` 就编译成它。

## D.6 类型速查

| 类型 | 写法 | 说明 |
|---|---|---|
| 整数 | `i1` `i8` `i16` `i32` `i64` `i128` `iN` | **任意位宽** |
| 浮点 | `half` `float` `double` `fp128` `x86_fp80` `ppc_fp128` | `half` 是 16 位 |
| 指针 | `ptr` | LLVM 18 只有这一种 |
| 数组 | `[10 x i32]` | |
| 结构体 | `{ i32, i8 }` | 有填充 |
| 打包结构体 | `<{ i32, i8 }>` | 无填充 |
| 向量 | `<4 x i32>` | SIMD |
| 标签 | `label` | 只能用于 `br`/`switch` |
| 空 | `void` | 只能作返回类型 |

### C 类型 → IR 类型

| C | IR | 参数属性 |
|---|---|---|
| `char` / `signed char` | `i8` | `signext` |
| `unsigned char` | `i8` | `zeroext` |
| `short` | `i16` | `signext` |
| `unsigned short` | `i16` | `zeroext` |
| `int` | `i32` | — |
| `unsigned` | `i32` | — |
| `long` / `long long`（Linux x86-64） | `i64` | — |
| `_Bool` | `i1` | `zeroext` |
| `float` | `float` | — |
| `double` | `double` | — |
| `long double`（x86-64） | `x86_fp80` | 目标相关 |
| 任何指针 | `ptr` | — |
| 数组作参数 | `ptr` | 退化为指针 |

### 特殊值

| 写法 | 含义 |
|---|---|
| `null` | 指针的零值 |
| `undef` | 「随便什么值」，每次读可以不同 |
| `poison` | 有毒值，污染下游；影响可观测行为即 UB |
| `zeroinitializer` | 全零，可用于任何类型 |
| `true` / `false` | `i1` 的 1 / 0 |
